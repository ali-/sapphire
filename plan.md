# Sapphire implementation plan

Review baseline: engine sources present on 2026-11-04. Reviewed all seven engine translation-unit files (5,404 lines, including embedded Metal shaders), the font resource header/size, project instructions, memory notes, and ignore rules. `_game/` changes are limited to moving grass-specific behavior back into `_game/game.cpp` and the compatibility edits specified below. This is a source review, not a measured performance certification; no runtime or GPU regression tests were run. Implement the changes below completely before compiling or running any tests. Do not add test harnesses or testing tasks to this work.

Preserve the single-translation-unit inclusion structure, SDL3-only dependency policy, public APIs, fixed-step scheduling, initial terrain residency, current streaming hysteresis/cadence, collision tolerances, lighting model, shadow resolution/filtering, transparency order, and mesh MarkDirty contract. No ECS rewrite, job system, renderer replacement, new physics solver, quality reductions, or unrelated game edits. Follow AGENTS.md formatting. This requested plan is the explicit exception to the no-documentation rule; create no additional documentation.

## core.cpp

Cause: WorldPartitioner::Rebuild clears residentCells, residentCellKeys and pending queues but leaves hasCellSelection and initialCellLoadComplete true. Update subsequently skips selection when the camera remains in the same cell and the loading range is unchanged. Creating an object after startup can therefore remove all partitioned residency indefinitely.

At Rebuild, force selection refresh and preserve surviving resident cell keys as specified below. Reset selection, initial-load and stream-time state on the disabled/no-camera path. The first activation synchronously populates the initial desired set; later streaming retains the one-cell-per-8ms policy.

Replace the six duplicated extrema assignments in IncludeBounds with Math::Include after try_emplace; preserve insertion behavior. Use std::deque<CellKey> for pendingCellLoads and pendingCellUnloads, replacing front erasure with pop_front. Deque supports the existing sort on unloads. Preserve load ordering, unload ordering, load-before-unload priority and timing. Add the explicit deque include to core.cpp rather than relying on graphics.cpp.

residentSet already deduplicates every object before deciding whether it belongs in residentRenderObjects. In addResident, return immediately when residentSet insertion fails, then append to residentObjects and conditionally to residentRenderObjects. Remove renderSet entirely. Preserve first-occurrence order and the source/cell filtering predicate. This eliminates a second hash set and insertion per eligible object without changing membership.

Add the Model and NormalMatrix overloads accepting precomputed axes specified under physics.cpp. Add the instance revision API and snapshot support specified under graphics.cpp.

Remove Mesh::windAnimated and its copying into partition meshes. Rename MeshInstance::variation to customData, retaining its float type and layout; the engine must not interpret it as wind phase.

Add Material::vertexModifierSource (std::string, empty by default). It contains a developer-supplied Metal function with this exact signature: `void ModifyVertex(thread float3& position, thread float3& normal, thread float4& color, float instanceData, float time, float4x4 model)`. Position and normal are in object-local coordinates after instancing and material displacement; color starts as the original vertex color; instanceData is customData or zero for non-instanced meshes. The modifier may change position, normal and color. Add Mesh::vertexBoundsPadding (Vector3, zero by default) and Mesh::vertexAnimated (bool, false by default). Padding is a nonnegative conservative object-local extent supplied by the developer; vertexAnimated marks time-dependent output for shadow invalidation. Include modifier source in Material::Key. Copy all three properties into partition meshes. These are generic vertex-processing facilities, with no vegetation defaults or formulas.

Implement partition-source invalidation instead of treating generated cells as permanent snapshots. Store a compact snapshot per source containing object identity, renderStatic/spatiallyLoaded, transform, Mesh pointer and MeshRevision, instanced state, and the material/render/modifier properties copied into generated cells. Before Update uses cached object pointers, compare the current owning objects vector against stored identities and snapshots without dereferencing removed objects. Rebuild when membership, classification, geometry or transform changes; compare geometry through MeshRevision, never by scanning vertices every frame. For changes limited to material/render/modifier properties, copy those properties to existing generated meshes without rebuilding geometry. Clear or rebuild derived cells before reading removed source pointers. Existing MarkDirty remains required for in-place vertex edits.

Preserve existing residency on a rebuild caused by source changes: retain the old resident cell keys by value, recreate cells, retain surviving resident keys, discard removed keys, and force selection refresh. Load newly required cells with the existing cadence, while the very first activation still loads its initial desired set synchronously. Reset initialCellLoadComplete only when there was no active partition selection (startup or reactivation). Selection must run immediately after every rebuild, even if camera cell and range are unchanged. This prevents both empty residency and repeated initial-load bursts.

## graphics.cpp

Cause: signatures cover geometry pointers/counts and revision, but omit instance pointer/count and omit instanced from BoundsSignature. GetMesh uploads instances only when geometry uploads or the instance buffer is absent. Resizing instances without MarkDirty can increase the draw instance count beyond uploaded capacity; toggling instanced can retain incompatible bounds. MarkDirty currently refreshes instances by unnecessarily reuploading base geometry.

Keep MarkDirty backward compatible: it still invalidates geometry and instances, including in-place edits. Add an internal instance snapshot containing instances.data(), instances.size(), and mesh.revision, plus instanced state where needed. Compare it in UpdateMeshSource independently of the mesh geometry signature and before the unchanged-source early return. Instance changes must invalidate draw bounds, cached RenderItem, and static shadow old/new bounds; they must mark the GPU instance stream dirty without marking base geometry dirty when only pointer/count changed. Include instanced in bounds invalidation. Empty/nonempty transitions must work without accessing vertices.front on empty geometry.

GetMesh must upload an instance stream when its snapshot is stale, and record the snapshot only after successful upload. Check instance byte count against Uint32 maximum before conversion. Use uploaded instance count for readiness verification; never issue a draw for more instances than were successfully uploaded. Do not hash every instance each frame. In-place edits still require MarkDirty. Add Mesh::instanceRevision and MarkInstancesDirty(), which increments only instanceRevision. Include instanceRevision in the instance snapshot. MarkDirty retains its existing broader effect. Instance-only changes must not upload base geometry.

Both main and shadow vertex shaders divide normals by max(abs(instanceScale), epsilon), losing negative scale signs. Use a shared helper in deformationShaderSource that computes a signed inverse scale: reciprocal when abs(component) exceeds the established small-scale threshold, zero otherwise, consistent with Math::NormalMatrix. Rotate the resulting normal and normalize safely when its squared length is nonzero. Use the helper in both shader paths. Preserve position transforms and deformation ordering. Do not change winding/cull policy as part of this fix.

Remove every windAnimated branch, windAmplitudes cache, windPadding calculation, hardcoded wind amplitude/frequency, color-alpha phase addition, color whitening and batching-time color-red scaling. Keep generic instancing and material displacement. Remove the wind fields from shader uniforms and CPU uploads; supply generic time separately in aligned uniform storage shared consistently with the Metal structs.

Implement vertexModifierSource by compiling its function into both main and shadow vertex shader variants and calling it after instance transformation and displacement. Provide an empty no-op function for the default path. Main-pass output color is the modified color. Compile and cache pipeline families by exact modifier source, preserving existing instanced, alpha, transparency and culling variants. Reuse the existing default family for empty source. Create variants once when first needed, release them at Graphics::Shutdown, and never compile per draw or per frame. Shader errors use the fatal error path below. No game shader text belongs in graphics.cpp.

Exclude meshes with nonempty vertexModifierSource from CPU static batching, because baking transforms changes modifier coordinates. Include source identity, vertexBoundsPadding and vertexAnimated in the relevant draw/bounds/shadow signatures. Expand the aggregate object-local bounds by vertexBoundsPadding after combining instances, then transform bounds to world space. Keep the existing material displacement bounds expansion. Route vertexAnimated meshes through dynamic shadow casters even when the object is renderStatic; static modifiers remain eligible for cached shadows. Apply this to directional and point shadows. Remove wind-specific batching keys and cache state rather than leaving unused replacements.

CreatePlane computes subdivisions+1 and z*rowSize using signed int before validation. Before allocation, normalize subdivisions >=1, compute counts in uint64_t, and reject counts exceeding MeshData::Validate GPU-byte limits with length_error. Only then convert or perform loop indexing. This bounds all subsequent int index arithmetic under the current vertex size limit.

UploadTexture uses Uint32 arithmetic for aligned mip offsets/total size and signed width*height in pixel loops. Validate positive dimensions, nonzero compatible stride, rowPitch >= rowBytes and nonnull pixels, then compute row sizes, aligned offsets and total sizes using uint64_t/size_t before narrowing to SDL Uint32 fields. Reject unrepresentable sizes before allocation or memcpy. CPU alpha mip generation specifically assumes four-channel byte pixels: reject incompatible format/stride combinations for that path instead of reading/writing four bytes under an arbitrary stride. Keep existing valid RGBA output and mip filtering exactly unchanged.

For uploads, command recording, resource creation and initialization, implement the graphics-specific ownership and error behavior specified under sapphire.cpp. Retain batching of preparation uploads separately from rendering.

## physics.cpp

Include source collider presence and isMesh classification in physics synchronization: generated colliders must stop participating immediately when the source no longer supplies a mesh collider, instead of retaining the old generated collider behavior. Skip the generated collider record when its source no longer has an eligible collider; do not add component-removal machinery.

FindCapsuleHit and FindEarliestHit already reject against record.bounds, which equals BoxBounds(record.box) for box obstacles. Remove the second identical BoxBounds/Overlaps test in their box branches; retain the narrow-phase calls.

ResolveOverlaps recomputes the moving shape/bounds for every candidate even when position has not changed. Compute its bounds before the candidate loop and refresh immediately after each positional correction. Never reuse bounds across a correction. Retain candidate order, all iterations, contact selection, grounding and velocity behavior. Avoid a new persistent cache or invalidation system.

In SyncColliders mesh handling, record.axes is computed and then Model recomputes the same trigonometry. Add a Math::Model overload accepting precomputed axes, and make the existing overload delegate to it. Use the prepared axes here. Keep the public existing overload and matrix arithmetic unchanged. Apply the same overload in PrepareDraw to avoid recomputing axes for model and normal matrices by adding a matching NormalMatrix overload accepting axes; the existing overload delegates after computing axes. Keep reciprocal-scale construction in that one implementation.

Remove unused Scene& parameters from private FindCapsuleHit, ResolveOverlaps and ResolveDynamicPairs, and propagate that simplification through private forwarding helpers where Scene becomes unused. Retain Scene parameters on SimulateCapsule and any path that reads gravity, and keep public Physics functions unchanged. Remove only checks of record.collider that are provably redundant: SyncColliders never appends a record without a collider. Do not remove nullable collider handling in BodyRecord.

BuildTree computes winding in local space. GetWorldTriangle applies signed scales, but the four mesh overlap/sweep callers pass unchanged tree.winding. An odd number of negative scale axes reverses world triangle orientation, so closed-mesh outward tests reject the wrong side.

For FindMeshOverlap, FindMeshSweep, FindCapsuleMeshOverlap and FindCapsuleMeshSweep compute effective winding once per query as tree.winding multiplied by the sign of transform.scale.x * transform.scale.y * transform.scale.z. Determine parity through component signs rather than multiplying magnitudes (avoids overflow/underflow). Pass effective winding to the existing triangle routines. Preserve existing singular-scale handling; do not alter BVH topology or raycast normal-facing behavior.

## sapphire.cpp

Make callback traversal safe for object creation through CreateObject/AddObject. Replace range-based traversal of the owning vector during Initialize, FixedUpdate, Update and GUI with index-based traversal that captures the phase-start object count and reacquires the owning vector entry before each callback. Appended objects do not enter a phase already in progress. Maintain an App-local set of initialized Object pointers. At startup and each frame before fixed updates, initialize uninitialized objects in creation order, including objects appended during initialization, then seed each new PhysicsBody::previousPosition and update partition residency. For Update/GUI, retain their current per-object order and call GUI only for initialized objects. Newly created objects wait until the next initialization boundary before receiving callbacks or participating in simulation/rendering: add Object::initializedForApp state, default true for engine-only usage; CreateObject/AddObject set it false while App is active, and App sets it true after Initialize. Partitioning skips pending objects and invalidates when initialization completes. Synthetic partition objects remain eligible. Restore standalone behavior when App exits. Do not expose internal initialization callbacks from collider synchronization. Direct destruction or erasure from Scene::Objects during a callback remains unsupported; this change supports the existing creation APIs without inventing a destruction API.

Verified unsafe paths: UploadBuffer/UploadTexture and GUI::Render memcpy into unchecked mapped pointers; BeginUploads uses an unchecked acquired command buffer; App uses an unchecked command buffer and ignores the swapchain acquisition boolean. Resource allocation can therefore turn recoverable failure into a null dereference. Do not scatter unrelated defensive checks through math or hot draw loops.

Implement checked creation/mapping at these boundaries with one coherent fatal GPU-operation error path (std::runtime_error containing operation and SDL_GetError is sufficient). Keep existing bool initialization APIs. Ensure temporary shaders, surfaces, transfer buffers and newly allocated destination resources are released on failure, and no resource is published as ready before successful recording. In UploadMesh, do not leave the cached GpuMesh referring to a released old buffer if replacement allocation fails. Commit replacement handles transactionally: allocate replacements before releasing old handles, and release unpublished replacements on failure. GUI mapping failure must occur before memcpy and before recording its copy pass.

App must check command acquisition and the return from SDL_WaitAndAcquireGPUSwapchainTexture. A successful call returning a null texture remains a normal minimized-window path. Track whether a command owns an acquired swapchain texture: never cancel it after acquisition. On fatal recording failure, close any begun pass, submit an acquired-swapchain command as required, or cancel an unacquired command, then shut down and return nonzero. Check submission failure and never reuse a submitted command. Catch engine exceptions at App's lifecycle boundary, log once and execute Shutdown once. Ensure unsubmitted upload commands and transfer ownership are also finalized safely on failure. Track successful window claim so Shutdown releases only a claimed window. Do not add GPU-idle waits to normal frames.

Use local scope guards for temporary resource ownership; do not create a general resource-management framework. Verify SDL ownership rules against the installed headers/docs before finalizing failure cleanup.

## gui.cpp

Check transfer-buffer creation and mapping before memcpy in Render, using the shared fatal GPU error behavior above. Preserve adjacent-texture batching, the fixed index buffer, reusable cycled vertex transfer buffer, font loading and image caching. Ensure partial Initialize failures release temporary shaders and leave Shutdown safe.

## input.cpp

GetKey/GetKeyDown/GetKeyUp only exclude UNKNOWN before array indexing. Reject values <= SDL_SCANCODE_UNKNOWN or >= SDL_SCANCODE_COUNT before any keyboard/pressed/released access. Apply equivalent bounds checks to key events before indexing in public ProcessEvent. Preserve key aliases, held-state merging, quick-tap edges, gamepad deadzone and repeat behavior.

## _game/game.cpp

Move the grass shader behavior into a Metal source string owned by GrassGenerator and assign it to each patch material through vertexModifierSource. Implement the existing formula there: add `color.r * length(model[1].xyz) / max(length(model[0].xyz), 0.0001) * sin(time * 1.5 + (color.a + instanceData) * 6.2831853) * 0.08` to position.x, then set color to float4(1.0). Retain original normals, matching existing behavior. Set vertexAnimated=true. Set vertexBoundsPadding.x to the maximum absolute tuft vertex color.r multiplied by 0.08 and the same object scale ratio, with y/z zero; refresh that padding when the patch scale changes. The game owns these constants, vertex-color meanings and phase interpretation.

Replace windAnimated assignments with that generic modifier configuration. Update any named variation references to customData; positional instance initializers retain their layout. Change GrassGenerator::Publish to MarkInstancesDirty so density/placement updates do not reupload tuft geometry. Preserve the existing random sequence, patch pool, surface sampling, density tiers, generation budgets, visuals, shadow setting and material settings. Do not replace GPU animation with per-frame CPU vertex or instance updates. Leave ObjLoader and other developer-designed generators in game.cpp; do not move their implementation or asset assumptions into engine files. Do not access Graphics private state.

## Retained algorithm decisions

Keep raycast synchronization on each public call because transforms and collider fields are directly mutable between queries. Keep the current dynamic-pair ordering and capsule-box narrow phase; no equivalent lower-cost replacement was established by this review. Keep cell-transition streaming selection and its hysteresis. These are explicit decisions, not tasks awaiting further design. The generic game-owned vertex modifier replaces the problematic static wind batching path. Keep GPUCompletionTime as completion-observation latency; do not relabel it as execution time.

## loading.cpp, resources/iosevka.sbf and project metadata

No changes. Keep public consumer APIs even when engine code does not call them. Remove only private code made unused by the explicit changes above. Do not add documentation, benchmark infrastructure or unrelated cleanup. Complete all specified implementation work before compilation or testing.
